# Changelog

## 1.0.0

The first release: your Claude Code usage in VS Code's status bar, set up in one click.

- **A bar per usage window:** the 5-hour window and the week (and a spend limit, where there's one), each with how much
  you've used, how long until it resets, and its own colour from 75% and 90%.
- **One click to set up:** the extension installs the small Claude Code plugin that reports your usage, keeps it in step
  with the extension, and removes it when you uninstall.
